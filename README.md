# Ubatcentralens Projektplan

* Projektplan + rapport färdiga.
* Fördjupad OOP (arv, polymorfism, designmönster).

## Kodstandard 
### Namnkonventioner
* Klasser skrivs i PascalCase (minKlass)
* Metoder och funktioner skrivs i snake_case (min_funktion)
* Variabler skrivs i snake_case (min_variable)
* Konstanter skrivs i UPPER_CASE (MAX_CASHE)

### Kommentarer och dokumentation
* Alla klasser och metoder ska ha en kort docstring som förklarar syfte och användning.
* Inline-kommentarer används sparsamt och bara när koden inte är självförklarande.

### Struktur
* Koden delas upp i moduler efter funktion (t.ex. movement.py, sensors.py, mm)
* Ingen onödig kod i main.py den ska bara starta programmet.

### Versionshantering
* Feature branches används för nya funktioner.
* Pull requests görs innan kod mergas till main.
* Commit-meddelanden ska vara korta och beskrivande
