# Ubatcentralen

## Mål 
* Projektplan + rapport färdiga.
* Fördjupad OOP (arv, polymorfism, designmönster).
* Effektiv filhantering för stora filer.
* Robust loggningssystem med dekoratorer.
* Enhetstester för centrala delar.
* Avancerad GUI med visualisering av ubåtar på karta.


## Arbetsmetod
* Kommunikation sker löpande via Discord samt Teams
* Vi arbetar agilt med Trello för planering och uppföljning.
* GitHub används för versionshantering och koddelning.
* Projektet delas upp i sprintar
